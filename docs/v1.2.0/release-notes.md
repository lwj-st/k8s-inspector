# K8s Inspector v1.2.0 Release Notes

## 主要变化

- 页面降噪：移除默认页面中的口号式和重复说明文案，保留错误、风险和确认类提示。
- 问题工作台：默认只看开放问题，已恢复和已忽略通过筛选查看；表格列顺序、截断和状态颜色按排障优先级调整。
- 问题详情：首屏聚焦结论、资源、证据和建议动作；不再为无法确定资源的问题生成泛化命令；已忽略问题可恢复显示。
- 巡检结果：状态巡检、日志巡检和模板检查各自展示本模块结果；模板未命中不再作为默认噪音展示。
- 名称空间证据抽屉：优先显示 Pod 总数、异常 Pod、CPU 和内存摘要，正常对象和技术字段默认折叠。
- 视觉主题：默认亮色主题，支持在左下用户菜单切换亮色/暗色并持久化。
- 用户菜单：左下用户卡片支持主题切换、更改密码和注销，支持外部点击和 Esc 关闭。
- 问题批量处理：问题工作台支持批量确认、批量忽略和批量恢复显示，部分失败会展示成功和失败数量。
- 问题处理记录：问题详情支持新增人工处理记录，确认、忽略、恢复显示和通知静默也进入时间线。
- 证据筛选与导出：问题详情支持按证据类型筛选，支持复制和下载脱敏 Markdown。
- 自动刷新：问题工作台支持自动刷新开关和间隔配置，刷新时不清空用户正在输入的批量备注。
- 维护静默：系统设置支持维护静默窗口，通知命中后抑制发送并记录“通知已静默”；静默结束后只发送一次仍开放问题摘要。
- 访问路径：同一版本支持根路径 `/`、子路径 `/inspector/`，以及同实例根路径 + `/inspector/` 双入口部署。
- Helm 和文档：新增根路径、子路径、双入口 values 示例，README 和 Chart 文档补充对应部署命令与 rewrite/strip path 注意事项。

## 兼容性

- 不删除 v1.0.0 和 v1.1.0 已有 API 字段。
- 不改变已有问题编码语义。
- 不扩大 Kubernetes 写权限，仍保持只读巡检边界。
- 同实例双入口要求 `/inspector` 入口在网关层 rewrite/strip path 到根路径；不剥离前缀的环境应使用子路径部署。
